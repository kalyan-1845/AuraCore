# 🌌 AuraCore AI Command Center - Elite V5.5 (Neural Debate Edition)

The most advanced local multi-agent orchestration platform. Featuring 94% Reasoning Depth and Adversarial Self-Correction.

## 🚀 Quick Launch
1. Run `Aura_Control.bat` from your desktop.
2. Select **[1] LAUNCH** to start the full stack (Ollama + FastAPI + Next.js).
3. Your dashboard will automatically open at `http://localhost:3000`.

## 💎 Elite Architecture

### 1. 🧠 Neural Debate Loop (Adversarial Reasoning)
- **5-Agent Evolution:** Strategist → Researcher → Reasoner (CoT) → Synthesizer → Neural Debate → Refiner.
- **The Grand Skeptic:** Actively searches for logical fallacies, security risks, and generic content.
- **The Visionary Optimist:** Defends the core brilliance and expands unique value.
- **Recursive Refinement:** Agents "fight" for up to 3 rounds to achieve **94% Reasoning Depth**.

### 2. 🛡️ Red Team Mode (Security Auditing)
- **Specialized v5.5 Mode:** Switches the entire pipeline into a Security Audit engine.
- **Penetration Tester Agent:** Attacks your logic/code for vulnerabilities.
- **Security Architect Agent:** Hardens and patches the system before final delivery.
- **Local Privacy:** Audit your most sensitive code without ever sending data to the cloud.

### 3. 🌐 Real-Time Intelligence & CoT
- **Chain of Thought (CoT):** Hidden internal monologue that maps logic before drafting.
- **Live Web Synchronization:** DuckDuckGo + News API integration for real-time data.
- **Company Intel Engine:** Deep profiling of tech stacks, hiring, and market position.

### 4. 🤖 Multi-Model Orchestration
- **Auto-Selection:** Dynamically picks the best model (Llama3, Mistral, CodeLlama) based on task.
- **Specializations:** General (Flux), Analyst (Research), Coder (Engineering), RedTeam (Security).

### 5. 📡 Neural Portability
- **Export Bridge:** Backup your AI's knowledge into a portable `.txt` state.
- **Restore State:** Clone your AI's memory on any machine instantly.
- **Train Files:** Locally ingest documents to expand the model's context.

## 🛠️ System Control
- **Shutdown:** Use option **[2]** in `Aura_Control.bat` to stop all processes.
- **Database:** Intelligence stored in `backend/aura_memory.db`.
- **License:** Developer mode enabled (ENABLE_LICENSE_CHECK = False).
